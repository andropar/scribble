Three ways to show what you mean

⌃⌥⌘S

Snapshot

Freezes every display. Draw and talk over the frozen screen. Hide the overlay, navigate somewhere else, take the next shot, all in one capture.

⌃⌥⌘R

Walkthrough

Records while you keep working. Hold a modifier to draw laser-pointer marks that fade. Agents cannot watch video, so the recording becomes a storyboard of up to 30 keyframes.

⌃⌥⌘T

Dictation

Voice only. The transcript lands on the clipboard as plain text, for the prompts you would rather say than type.

  • Arrow, box, circle, highlighter, pin make numbered marks. The pen is for sketches and stays exactly as drawn.
  • Several displays are captured together. In a walkthrough the cursor decides which one a keyframe comes from.
  • 4K and larger screens get an extra native-resolution crop around your marks, so small text stays readable.
  • Light on the chat. By default the clipboard carries the transcript and a file. Agents that read files open the images when they need them.

Nothing leaves your machine.

Transcription runs locally with Whisper: on the Neural Engine on a Mac, on the CPU or an NVIDIA GPU elsewhere. Captures live in a folder in your home directory and are deleted after 14 days. There is no server, no telemetry, and nothing to sign up for.

Questions

Which agents does it work with?

Anything you can paste into. Terminals (Claude Code, Codex) take the transcript text, which lists the image files by path. Chat apps and browsers (Claude, ChatGPT, Cursor) take the attached files. If one target wants something else, the tray menu can copy any recent capture again in another format, including a single composite image.

Is it really free?

Yes. It is an open-source project under the MIT license. There is no paid version.

Why does my system warn me when I open it?

The downloads are not signed with a paid developer certificate, so macOS Gatekeeper and Windows SmartScreen ask for confirmation the first time. The source and the build scripts are public, and the Windows and Linux downloads are built by GitHub Actions from that source.

How fast is the transcription?

On an Apple Silicon Mac a one-minute recording takes about five seconds once the model has warmed up. On Windows and Linux it runs on the CPU with a smaller English model by default; with an NVIDIA GPU and CUDA it uses the large one.

Does it understand languages other than English?

Not yet. Transcription is set to English.

What is different on Windows and Linux?

Same three modes and the same output, in a separate implementation with its own shortcuts. On Linux with X11 the capture toolbar is visible in walkthrough keyframes, and the capture tells the agent so. The Wayland mode is reduced and new; details are in the README.
